# 01 - 快速开始

## 目标

给出一个快手直播分享口令（形如 `##X56ZfKJb622Z1i7##`）或短链（`https://v.kuaishou.com/f/xxxx`），
最终得到一份**带声音、可拖动、时长完整**的本地 MP4。

## 前置

```powershell
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple av
```

验证：

```powershell
python -c "import av; print(av.__version__)"
```

## 全流程（7 步）

### 第 1 步 解析口令 → 回放页

```powershell
python ks_extract/resolve_ks.py "https://v.kuaishou.com/f/X56ZfKJb622Z1i7"
```

期望输出里有：

```
FINAL : https://v.kuaishou.com/fw/playback/1499544558?...&subBiz=LIVE_PLAYBACK...
```

其中 `1499544558` 就是**回放 ID**。

### 第 2 步 抓取回放页 HTML

把第 1 步 `FINAL` 的完整 URL 填到 `ks_extract/extract_playback.py` 顶部的 `URL`，然后：

```powershell
python ks_extract/extract_playback.py
```

产物：`playback_body.html`，同时打印出页面里所有 `m3u8 / mp4 / flv / ts` 直链。

### 第 3 步 挑选目标回放

```powershell
python ks_extract/pick_replay.py
```

会列出所有回放，按 `清晰度 + 时长` 排序，并自动选中带 `GameAvcHd` 的那条（游戏直播最高清源），
随后试拉一次 manifest 确认能播。

产物：`replay_list.json`。

### 第 4 步 下载分片

把第 3 步选中的 m3u8 完整 URL（**含 `auth_key`**）填到 `ks_extract/dl_replay.py` 顶部的 `M3U8`：

```powershell
python ks_extract/dl_replay.py
```

8 线程并发、断点续传（已存在的分片直接跳过）。看到 `DL_DONE` 即完成。

> `auth_key` 是**带签名和过期时间的**。如果报 403，回到第 3 步重新拉一次页面拿新链接。

### 第 5 步 拼接 TS

见 [`03-下载与拼接.md`](03-下载与拼接.md)。核心是一句二进制顺序拼接：

```powershell
$out = [System.IO.File]::Create('G:\ksrec\replay\merged.ts')
Get-ChildItem 'G:\ksrec\replay\segs\*.ts' | Sort-Object Name | ForEach-Object {
    $b = [System.IO.File]::ReadAllBytes($_.FullName)
    $out.Write($b, 0, $b.Length)
}
$out.Close()
```

### 第 6 步 TS → MP4 重封装

```powershell
python ks_extract/remux_full.py
```

不解码、纯透传，900 MB 约 **8 秒**完成。

### 第 7 步 验证

```powershell
python verify/verify_full.py      # 容器 / 流 / 编码 / 解码抽帧
python verify/verify_audio.py     # 音频全程解码，采样点计数
python verify/verify_timeline.py  # 关键帧分布 + 音视频漂移
```

三个脚本分别打印 `VERIFY_OK` / `AUDIO_OK` 即为通过。

## 完成后

Copy-Item 'G:\ksrec\replay\replay_full.mp4' `
