# 02 - 链接解析

## 快手分享链接的三种形态

| 形态 | 例子 | 说明 |
| --- | --- | --- |
| 分享口令 | `##X56ZfKJb622Z1i7##` | App 内分享复制出来的文本，中间那串是 **shareToken** |
| 短链 | `https://v.kuaishou.com/f/X56ZfKJb622Z1i7` | 把 shareToken 塞进 `/f/` 路径 |
| 真实页 | `https://v.kuaishou.com/fw/playback/1499544558?...` | 短链 302 之后落地的地方 |

## 核心结论

**快手短链不需要逆向解码，直接跟随 302 就行。**

之前误以为短链「很难解码」——因为短链码本身（`X56ZfKJb622Z1i7`）不是 base64、也不是 ID 编码，
它就是一个**不透明 token**，值本身没信息量。真正要做的是：

1. 取出 `##...##` 之间的字符串；
2. 拼成 `https://v.kuaishou.com/f/<token>`；
3. 发一个带移动端 UA 的 GET；
4. 读响应里的 `Location` / 最终 URL。

## 关键代码

`ks_extract/resolve_ks.py` 的核心：

```python
UA = ("Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 "
      "(KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1")

req = urllib.request.Request(url, headers={
    "User-Agent": UA,
    "Accept": "text/html,application/xhtml+xml,*/*",
    "Accept-Language": "zh-CN,zh;q=0.9",
})
with urllib.request.urlopen(req, timeout=25) as r:
    final = r.geturl()          # ← urllib 自动跟随 302
    body  = r.read().decode("utf-8", "ignore")
```

三个要点：

- **必须用移动端 UA**。桌面 UA 打不开分享落地页。
- `urllib.request` 默认跟随重定向，`r.geturl()` 直接给最终 URL，不用手动处理 302。
- 要用 `urllib.error.HTTPError` 兜底：某些令牌会直接 302 到 App Scheme（`ksnebula://`），
  此时 `geturl()` 拿不到，需要读 `e.headers["Location"]`。

## 从最终 URL 里提取什么

```python
PATTERNS = [
    (r"/profile/([A-Za-z0-9_\-]+)", "profile id"),      # 主播主页
    (r"/live/([A-Za-z0-9_\-]+)",    "live id"),         # 直播间
    (r"userId=([0-9]+)",            "userId"),          # 数字用户 ID
    (r"principalId=([A-Za-z0-9_\-]+)", "principalId"),  # 主播标识，形如 YyXx-828924
    (r"/f/([A-Za-z0-9_\-]+)",       "short code"),      # 短链码
]
```

补充：如果第一次落地页是**直播间页**而不是回放页，页面正文里还会有
`"authorId"`、`"principalId"`、`"photoId"` 等字段，用正则从 body 里再捞一遍。

## 本项目的实测解析记录

```text
INPUT : https://v.kuaishou.com/f/X56ZfKJb622Z1i7
STATUS: 200
FINAL : https://v.kuaishou.com/fw/playback/1499544558?cc=share_copylink
        &kpf=ANDROID_PHONE&shareMethod=token&kpn=KUAISHOU&subBiz=LIVE_PLAYBACK
        &shareId=19115508202223&shareToken=X56ZfKJb622Z1i7&shareMode=app
        &shareObjectId=5228679375865664634
  short code   : X56ZfKJb622Z1i7
```

- 路径段 `fw/playback/<id>` 里的 `<id>` = **回放 ID**（`1499544558`）
- `subBiz=LIVE_PLAYBACK` 明确标识这是**直播回放**而不是短视频
- `shareToken` 与短链码一致，可以直接复用

## 另一个可用入口：主播主页

如果手上只有主播 ID，不需要口令也能进：

```powershell
python ks_extract/resolve_ks.py "https://live.kuaishou.com/profile/YyXx-828924"
```

实测 200 返回，主页里含 `showPlayback: true` 标记位。
不过要注意：**主页的 `list` 字段可能是空的**——是否有回放由主播端设置决定，
所以主页只适合做「可用性探测」，真正拿 m3u8 还是要走回放分享页。
