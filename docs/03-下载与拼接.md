# 03 - 下载与拼接

## 3.1 从回放页 HTML 里捞 m3u8

回放页是一张 SSR 页面，所有播放地址都以 JSON 形式内嵌在 HTML 里（不是 XHR 异步取），
所以**不需要跑无头浏览器**，直接正则就够。

```python
PATTERNS = [
    (r'https?://[^\s"\'<>\\]+\.m3u8[^\s"\'<>\\]*', "M3U8"),
    (r'https?://[^\s"\'<>\\]+\.mp4[^\s"\'<>\\]*',  "MP4"),
    (r'"playUrls"\s*:\s*\[([^\]]*)\]',            "playUrls"),
    (r'"srcNoMark"\s*:\s*"([^"]+)"',              "srcNoMark"),
    (r'"duration"\s*:\s*(\d+)',                   "duration"),   # 毫秒
    (r'"photoId"\s*:\s*"([^"]+)"',                "photoId"),
    (r'"livePlaybackClarityLevel"\s*:\s*"([^"]+)"', "clarity"),
]
```

两个容易踩的点：

- JSON 里的斜杠可能是转义的：`\u002F` 或 `\/`。捞出来先做一次
  `val.replace("\\u002F", "/").replace("\\/", "/")`。
- 时长字段 `duration` 单位是**毫秒**。换算 `int(d)/60000` 得到分钟。

## 3.2 挑哪一条

同一次直播会产生多条 m3u8（不同清晰度 + 是否带游戏画面）。本项目实测 5 条，
命名规律：

```text
JsQSVN0Ra3Q_GameAvcHdL1Lto.1789558283798-5163925.0-16.m3u8
         ^^^^^^^^ ^^^^^ ^^
         业务     编码  清晰度档
```

- 含 `GameAvcHd` → 游戏画面 + H.264 + 高清，**优先选**
- 尾部 `-16` 是时长相关档位，数字越大越长
- `<13位时间戳>` 段可用于确认是哪一场直播

挑选策略（`pick_replay.py`）：去重 → 优先 `GameAvcHd` → 没有就取列表最后一条，
然后把该 URL 的 `duration_ms` 打印出来人工核对。

> 本项目实测选中：`...1789558283798-5163925.0-16.m3u8`，`start = 2026-09-16T11:31:23.798Z`
> = 北京时间 **19:31:23**，与开播时间对得上。

## 3.4 分片下载器设计

`ks_extract/dl_replay.py` 的四个设计点：

**① 8 线程并发**

```python
WORKERS = 8
with ThreadPoolExecutor(max_workers=WORKERS) as ex:
    futs = {ex.submit(worker, t): t for t in pending}
    for fut in as_completed(futs):
        ...
```

**② 断点续传 —— 靠文件存在性判断，不用额外状态文件**

```python
pending = [t for t in tasks if not (os.path.exists(t[2]) and os.path.getsize(t[2]) > 0)]
```

**③ 原子落盘，避免「半个分片」污染**

```python
data = fetch(url)
tmp = path + ".part"
with open(tmp, "wb") as f:
    f.write(data)
os.replace(tmp, path)          # 同一卷上是原子操作
```

## 3.5 TS 拼接

### 为什么不用 ffmpeg concat

本机精简版 ffmpeg 不认 `-safe` 参数：

```
Unrecognized option 'safe'
```

### 正确做法：二进制直接顺序拼接

MPEG-TS 就是 188 字节定长包流，**分片边界天然对齐**，直接首尾相接即可，无需任何重封装。

```powershell
$src = 'G:\ksrec\replay\segs'
$dst = 'G:\ksrec\replay\merged.ts'
$out = [System.IO.File]::Create($dst)
Get-ChildItem -LiteralPath $src -Filter '*.ts' |
    Sort-Object Name |
    ForEach-Object {
        $b = [System.IO.File]::ReadAllBytes($_.FullName)
        $out.Write($b, 0, $b.Length)
    }
$out.Close()
```

> **注意**：必须 `Sort-Object Name`，且分片文件名是 `%05d.ts` 零填充格式，
> 否则 `10.ts` 会排在 `2.ts` 前面，拼出来整段错乱。

### 验证拼接正确性

拼接后第一个字节必须是 `0x47`（TS sync byte），且每 188 字节出现一次：

```powershell
$fs = [System.IO.File]::OpenRead('G:\ksrec\replay\merged.ts')
$buf = New-Object byte[] 1880
$fs.Read($buf, 0, 1880) | Out-Null
$fs.Close()
$ok = 0
0..9 | ForEach-Object { if ($buf[$_ * 188] -eq 0x47) { $ok++ } }
Write-Output "sync $ok/10"
```

用 Python 抽检三个分片（`test_dl.py`）实测：

```text
seg0 462856 bytes  sync=50/50
seg1 863672 bytes  sync=50/50
seg2 943760 bytes  sync=50/50
```
